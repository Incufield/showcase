# Incufield Showcase

Projects built by Incufield students.

## Browse

Live site: https://incufield.github.io/showcase

## Submit your project

You keep your code in your own GitHub account. This repo only holds a short
description and a link, so we can build the showcase site.

1. Publish your project in **your own** GitHub repo with a clear README.
2. Fork this repo.
3. Copy `students/_TEMPLATE.md` to `students/<cohort>/<your-github-handle>.md`.
4. Fill in every field.
5. Open a pull request and complete the checklist.

A mentor reviews it. Once merged, your entry appears on the site within a few
minutes.

## What we accept

- The project must work. Include a demo link or a short video.
- The README must explain what it does and how to run it.
- No secrets in the repo.

## Your rights

- **You own your work.** Merging a pull request gives us a license to display
  and promote it. It does not transfer ownership.
- **You choose what is public.** Use a display name you are happy to have
  public forever. A GitHub handle is fine. We never publish your email, phone
  number, or address.
- **You can take it back.** Open an issue and we will remove your entry.

## Reporting a problem

- Content that infringes your copyright: see [DMCA notices](DMCA.md).
- Anything else: open an issue.
